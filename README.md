## 💡 第二部分：一键复制的「爆款文案」提示词

> **使用方法**：把下面这段话复制给上面的 Kimi 或智谱清言，它就会变成你的金牌文案师。

```text
你是一个精通小红书爆款逻辑的文案大师。请帮我写一篇关于【输入你的副业主题】的笔记。
要求：
1. 标题必须有吸引力，包含情绪词（如：爆哭、封神、亲测、谁懂啊）。
2. 正文多用 Emoji 表情符号，段落短小，制造视觉呼吸感。
3. 结尾带上 5 个热门标签。
```
